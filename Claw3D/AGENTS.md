# Module Contract — Claw3D Isometric Engine (`Claw3D`)

Parent DOX: [AGENTS.md](../AGENTS.md)

## Scope & Responsibility

This subtree contains the 3D isometric office canvas rendering pipeline powered by Three.js and React Three Fiber (R3F).

- **Camera**: Orthographic camera centered at `x:0, y:12, z:18` with zoom controls.
- **Office Spatial Grid**: Furniture placement, desk nodes, wall layouts, and character sprite rendering.
- **Workforce Sync**: Synchronizes 3D workforce avatar members with Paperclip backend state.
