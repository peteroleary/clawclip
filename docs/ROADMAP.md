# Product Roadmap

> The strategic feature trajectory for ClawClip.

## Phase 1: Foundation (Completed)
- [x] Basic React DOM structure.
- [x] Setup AG-Kit integration.
- [x] DOX SOP Documentation framework.

## Phase 2: Immersive OS (Current)
- [x] Immersive screens (Wallet, Team, Targets, Projects, Kanban, Scheduling, Facilities, Directory, Memory, Artifacts, Comms).
- [x] Discovery Marketplace (Skills, MCP, Connectors, Tools, Templates).
- [ ] Drag and drop functionality for Kanban task cards.
- [ ] Connect Firebase database to UI screens.

## Phase 3: Spatial Engine Integration
- [ ] Sync Three.js `Claw3D` engine with Zustand `workforce` state.
- [ ] Allow users to place furniture and desks on the spatial grid.
- [ ] Implement camera tracking to follow selected employees/agents.

## Phase 4: Autonomous Agents
- [ ] Wire the Comms `/task` command to the AG-Kit backend for automated task creation.
- [ ] Deploy Agent Swarms to monitor Slack webhook streams and automatically categorize insights in the Targets screen.
